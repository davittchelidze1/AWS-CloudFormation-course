How it works

1

Bucket

CloudFormation creates an AWS::S3::Bucket with a WebsiteConfiguration pointing to index.html and error.html.

2

Policy

An AWS::S3::BucketPolicy allows anyone to s3:GetObject, so visitors can read the site files.

3

Upload

The HTML, CSS and JavaScript files are uploaded to the bucket and served from the static website endpoint.
